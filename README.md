# Regalo para Bianca

Una carta interactiva con animación, música y recuerdos.

## Publicar con GitHub Pages

Este repositorio ya contiene todo lo necesario para funcionar. Es importante subir la carpeta `assets` completa junto con `index.html`; allí están la canción y todas las fotografías.

1. Abre **Settings → Pages** en el repositorio de GitHub.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama **main**, la carpeta **/(root)** y pulsa **Save**.
4. Espera uno o dos minutos y abre el enlace que mostrará GitHub Pages.

En teléfonos, la experiencia comienza al tocar **Comenzar nuestra historia ♫**. Ese toque permite iniciar la música y la animación al mismo tiempo.
